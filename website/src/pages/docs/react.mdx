# React & client

For a browser dashboard, Breadcrumb ships a typed client, React hooks, and a headless kit — the same contract as `bc.api`, over HTTP.

## React hooks

```bash
npm i @breadcrumb-sh/react
```

Wrap your dashboard in a `BreadcrumbProvider` (inside a react-query `QueryClientProvider`), then read data with hooks:

```tsx
import { QueryClientProvider } from "@tanstack/react-query";
import { BreadcrumbProvider, useSessions, useStats } from "@breadcrumb-sh/react";

function App() {
  return (
    <QueryClientProvider client={qc}>
      <BreadcrumbProvider basePath="/admin/traces">
        <Dashboard />
      </BreadcrumbProvider>
    </QueryClientProvider>
  );
}

function Dashboard() {
  const { data: stats } = useStats({ since: Date.now() - 7 * 864e5 });
  const { data } = useSessions({ environment: "production" });
  // …render it however your product looks.
}
```

Hooks: `useSessions`, `useTraces`, `useRuns`, `useTrace`, `useSpan`, `useCost`, `useStats`, `useEnvironments`. Each takes the same filters as `bc.api` and returns a react-query result.

## Typed client

Framework-agnostic — use it anywhere in the browser or in another service.

```ts
import { createBreadcrumbClient } from "@breadcrumb-sh/core/client";

const client = createBreadcrumbClient({ basePath: "/admin/traces" });
const { items } = await client.listSessions({ status: "error" });
```

## Headless kit

The view logic — nobody should rebuild span-tree assembly. Import it and render your own components.

```ts
import { buildTree, asMessages, fmtCost } from "@breadcrumb-sh/core/kit";

const tree = buildTree(spans);        // nested spans, same-name siblings grouped
const chat = asMessages(span.input);  // detect + parse chat-shaped payloads
fmtCost(0.0042);                       // "$0.0042"
```

Three levels, one contract underneath: server SDK (`bc.api`) → typed client → React hooks, with the kit for rendering. Pick whichever fits your app.
